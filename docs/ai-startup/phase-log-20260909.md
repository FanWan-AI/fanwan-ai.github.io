## 第二轮：日报与案例阅读布局

根据用户对正文过宽、大标题过强的反馈，参考论文中心的紧凑标签栏与卡片排版，仅修改 startup HTML/CSS，后台和公开文章内容保持不变。

- 总内容区最大宽度从 1180px 收至 1040px；超宽屏也不再继续拉伸。
- 标签栏与内容左对齐，以 46px 高的紧凑按钮替代大面积双栏选项；保留 ARIA tabs、键盘焦点和 Enter 确认。
- 日报标题上限从 48.8px 降为 28px，并平衡换行；摘要限制在 760px。数量/来源统计改为摘要下方的小型信息标签。
- 深度机会按单列卡片排列，卡片内部为双栏分析，手机切为单栏，避免次要卡片中挤入三列长文字。
- 案例列表配图桌面宽 280px、平板宽 220px、手机高 160px；案例卡片标题最高 24px。
- 案例详情外框上限 800px，正文、结论及来源区上限 720px；详情标题由最高 64px 降为 32px，长文保留 16px 字号与 1.9 行高。
- 深色模式的“阅读全文”按钮使用固定深蓝底白字；模块 CSS 增加版本参数，减少旧样式缓存影响。
