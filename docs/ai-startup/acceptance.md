# 总验收清单

## 产品

- [ ] AI 工坊只新增一个“AI 创业”卡片，且已停用的理财、每日学堂、游戏中心不显示、不挂载。
- [ ] 页面只有“机会日报”和“案例解剖”两个一级模块。
- [ ] 日报最多 10 条，前三条为深度卡，其余为紧凑卡；少于 10 条时不补水文。
- [ ] 案例正文结构来自故事本身，不是固定章节模板。

## 内容可信度

- [ ] 每条机会至少 2 个独立来源，关键断言可追溯。
- [ ] 数字、日期与监管信息有来源，未知项明确标注。
- [ ] 每条包含失败风险和最快证伪动作。
- [ ] 验证器失败时不覆盖公开最新版。

## 工程

- [ ] 密钥只存在于 GitHub Secrets；仓库和前端没有 API Key。
- [ ] Schema 校验、业务规则、URL 安全、超时重试和原子写入有自动测试。
- [ ] 离线 fixture 能完整生成并验证公开 JSON。
- [ ] GitHub Actions 的日更、周更与 Pages 部署路径正确。
- [ ] 仅提交本模块相关文件，不触碰现有 ModelSwatch 临时数据。

## 前端

- [ ] 360px、768px、1440px 宽度无横向溢出、裁切或重叠。
- [ ] 明暗主题均有足够对比度，键盘焦点清晰。
- [ ] 标签切换、案例打开/返回、来源展开、复制链接、日期回退可用。
- [ ] 数据缺失、网络失败、空日报和旧版缓存都有明确状态。
- [ ] 中文、英文、西班牙语外壳切换不报错，内容字段有合理回退。

## 发布

- [ ] 本地 HTTP 预览通过浏览器视觉检查。
- [ ] 控制台无新增 error。
- [ ] Git diff 经总验收后提交并推送，记录 commit hash。
