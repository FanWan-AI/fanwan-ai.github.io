## 🌍 一、模块定位与目标

> **一句话定义**
> 构建一个人人可懂、日日精进的理财学习引擎，让AI帮你每天增长一点“财富脑”。

**目标人群**

* 理财/投资小白
* 上班族、学生、自由职业者
* 想搞懂“钱是怎么运转”的人

**核心理念**
📈 从“存钱思维” → “理财思维” → “资产配置思维”
AI 理财助手不只是讲知识，而是每天让用户**掌握一个可落地的理财思维或投资工具**。

## 📚 三、AI理财助手的知识体系（从0到财富自由）

### 🌱 Level 1：理财启蒙

* 复利原理（Compound Interest）
* 通货膨胀与购买力
* 消费、储蓄与预算
* 资产与负债的区别（Rich Dad 思维）
* 银行账户与信用体系

### 💎 Level 2：投资入门

* 股票、债券、基金、ETF
* 什么是指数与股息
* 投资风险与回报
* 时间与波动的关系
* 市场周期与行为经济学

### 🏦 Level 3：宏观与微观经济学基础

* GDP、CPI、利率、货币政策
* 供需关系与价格机制
* 企业财务报表入门（ROE、EPS、负债率）
* 中央银行与金融系统

### 🧭 Level 4：资产配置与投资策略

* 长期投资 vs 短期投机
* 股票、债券、黄金、房地产的比例
* 风险分散原则（Diversification）
* 定投与价值投资的区别
* 行为偏差与投资心理学

### 🌐 Level 5：数字资产与未来趋势

* 比特币与区块链原理
* DeFi（去中心化金融）
* 人工智能与金融市场
* ESG 投资与可持续财富

### 🦾 Level 6：财富自由实践

* 个人财务报表管理
* 被动收入模型（租金、分红、基金收益）
* 税务与理财（税后收益优化）
* 理财目标设定与复盘

## ⚙️ 四、自动更新机制（技术层面）

| 环节          | 说明                                                             | 工具方案                      |
| ----------- | -------------------------------------------------------------- | ------------------------- |
| **1. 自动选题** | 每日主题由AI从知识树中选取未讲解或热门主题                                         | 内置`topics.json` + LLM选题算法 |
| **2. 内容生成** | 调用 LLM（DeepSeek/ChatGPT API）→ 生成中英双语课文 + 知识卡                   | LLM prompt模板：`每日理财课`      |
| **3. 自动发布** | GitHub Action 定时运行脚本，将生成内容写入 `/data/finance-daily.json` 并 push | GitHub API                |
| **4. 前端展示** | 网站读取 JSON 渲染卡片（可切换中/英文）                                        | JS Fetch + Markdown 渲染    |
| **5. 可选功能** | 每周总结生成「理财周刊」                                                   | LLM summarizer            |
