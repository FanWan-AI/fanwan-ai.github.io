AI 每日学堂模块优化与落地方案
背景与现状
当前个人网站的 AI Lab 中列出了多个模块，其中“AI 每日学堂”处于 Beta 排队状态，没有实际功能页面。根据仓库文件分析（ai-lab.html 与 lang.js），这个模块的目标是“构建核心 AI 知识体系，帮助用户通过日积月累应对技术变革”[1]。当前 lang.js 已存在该模块的多语言标题和描述键（module_ai_daily_academy_title、module_ai_daily_academy_desc），但未对应任何实现[2][3]。与此同时，网站已有成熟的模块 “AI 理财助手”（ai-wealth.html 和 tools/wealth/wealth.js），其页面和脚本可作为模板[4]。
为了让“AI 每日学堂”成为真正的学习与实践平台，需要结合现有代码结构（HTML 模板、JavaScript 模块、i18n 系统等）进行优化，并制定可落地的开发计划。
功能设计原则
1.渐进式学习与微课程：延续 Beta 阶段的设定，提供每日 5–10 分钟的微课。内容覆盖基础 AI 概念、算法、应用案例，由系统按用户兴趣和难度自动推送。
2.实践驱动：每节课配有简短的练习或小项目，嵌入在线代码运行环境或交互式问答，鼓励学以致用。
3.多语言与无障碍：利用现有 i18n 框架扩展更多文本（课程说明、按钮文案等），并提供音频朗读功能，符合不同用户需求。
4.反馈与成长：设置进度跟踪、积分奖励和排行榜，结合用户反馈改进内容，让学习长期可持续。
具体实现方案
1. 页面结构与路由
1.新增页面 lab/ai-daily-academy.html：
2.复制 lab/ai-wealth.html 的整体结构作为基础，保留顶部导航、Hero 区和底部结构[4]。
3.Hero 区域：修改标题、描述和背景图，突出每日学习与核心知识构建。例如：“AI 每日学堂：每天 10 分钟，构建你的 AI 核心知识体系”。
4.主内容区域：将财富模块的 “每日课程”和 “市场动态” 面板替换为以下两栏：
o“今日课程”面板：展示一张卡片，包含主题、简介、难度标签、音频播放按钮、练习入口等。支持分页浏览历史课程。
o“学习进度”面板：显示累计完成课程数、积分排行与徽章，提供学习日历视图和设置目标。该面板亦可用于展示社区讨论或课程评论。
5.保留页脚的免责声明，并根据需要调整内容，例如强调课程仅供学习参考，不构成专业建议。
6.路由更新：在 ai-lab.html 中，将“AI 每日学堂”的卡片按钮由 Beta 队列切换为指向新页面：
7.删除或隐藏 Beta 申请排队中 按钮，改为 立即体验 链接指向 /lab/ai-daily-academy.html。[1]
8.更新 progress bar 数据及 data-status 属性，表示上线状态。
9.导航栏入口：可在网站主导航或 AI Lab 导航中新增“每日学堂”快捷入口，方便用户快速访问。
2. 脚本开发
1.创建 tools/academy/academy.js：作为该模块的核心前端脚本，可参考 tools/wealth/wealth.js 的结构和逻辑。主要功能包括：
2.数据源配置：设置 DAILY_URL 指向存储每日课程数据的 JSON 文件（可以放置在 /data/ai/daily-academy/ 文件夹中，如 YYYY-MM-DD.json），并设置缓存策略。
3.国际化函数：复用现有 lang.js 翻译函数（如 t(...)），并定义新的文本键，例如 daily_today_title、daily_practice_button、daily_completed_tag 等。
4.渲染函数：编写 renderDaily() 函数，从 JSON 加载今日课程，生成课程卡片，包括标题、简介、难度标签、参考链接以及音频文件（如果有）。同时编写 renderProgress() 函数，读取本地存储中的学习记录，计算进度并更新进度视图。
5.交互逻辑：
o点击 播放音频 按钮时，使用浏览器音频 API 播放对应课程的 TTS 音频文件，可借助 generate-daily.mjs 类似的脚本在后端生成音频[4]。
o点击 开始练习 时，打开弹窗或页面显示问题列表（选择题、填空题或小编程任务），用户提交答案后即时反馈并记录正确率。
o支持分页或日历选择，浏览过往课程并重新学习。
6.本地存储与缓存：
7.使用浏览器 localStorage 或 IndexedDB 存储已完成课程 ID、学习时间、得分等信息，供进度统计和排行榜使用。
8.引入简单缓存策略，与财富模块的 cache 函数类似，避免重复请求数据[4]。
9.集成到 Service Worker：如果网站已有 PWA 功能，则在 Service Worker 中添加新资源的缓存配置，包括课程数据和音频文件，提升离线体验。
3. 后端与数据管理
1.课程数据格式：每节课程以 JSON 文件存储，包括以下字段：
2.id：课程唯一标识
3.date：发布日期
4.title/subtitle：标题与副标题，多语言支持
5.content：正文 HTML 或 Markdown，可内嵌图片、公式
6.difficulty：难度等级
7.practice：练习题数组（题干、选项、答案、解析）
8.references：参考文献或外部链接列表
9.tts_url：音频文件地址（可通过 Python 脚本 tts_daily.py 或类似程序生成）[4]。
10.生成与维护脚本：在 tools/academy/ 下创建生成脚本，如 generate-daily.mjs，用于根据 Markdown 或其他源文件生成 JSON 数据和 TTS 音频。可借鉴财富模块的 generate-daily.mjs；同时在仓库中创建 tools/academy/tts_daily.py 用于批量生成 TTS。
11.课程发布流程：编写 README 或文档说明，规范如何撰写和发布新课程；可使用 GitHub Actions 自动生成 JSON 和音频，并部署到 data/ai/daily-academy 文件夹。
4. 国际化与可访问性
1.更新 lang.js：为“每日学堂”添加新功能的翻译键。例如：
2.daily_today_title：今日课程
3.daily_practice_button：开始练习
4.daily_completed：已完成
5.progress_percentage：完成度 %s%%
6.根据需要添加练习反馈、排行描述等。
7.多语言音频：为不同语言生成对应的 TTS 音频，允许用户切换语言后自动切换音频。可以在课程 JSON 中加入多语言音频 URL。
8.可访问性：在 HTML 中为按钮添加 aria-label；为音频控件提供键盘操作；调整配色方案以符合无障碍标准。
5. 与现有系统集成
1.修改 script.js：在 initAiLabExperience() 函数中加入对每日学堂进度的更新逻辑，类似于加载其他模块的进度条[4]。
2.主题与组件复用：沿用现有 CSS 样式，复用按钮、卡片等组件，保证视觉风格统一。
3.测试与部署：在本地开发完成后，通过 GitHub Pages 预览，进行跨浏览器测试。上线前检查 i18n 翻译、响应式布局、移动端体验与加载性能。
开发时间线建议
1.需求梳理和设计（1 周）：确定课程结构、交互流程、数据格式。评审参考页面及脚本，完成原型设计。
2.前端开发（2 周）：编写 ai-daily-academy.html 和 academy.js，实现课程加载、进度管理和练习功能。
3.数据准备与后端脚本（2 周）：构建课程生成脚本，准备至少 7 天的微课程示例，生成对应 JSON 和 TTS。
4.国际化和无障碍处理（1 周）：完成所有文本翻译，配置音频文件并进行可访问性测试。
5.测试与优化（1 周）：修复 bug，优化性能，确保离线缓存与 PWA 功能正常。
6.上线与运营：发布新模块，将 AI Lab 卡片状态更新为已上线；通过博客或公告介绍新功能，收集用户反馈持续迭代。
小结
通过在现有代码基础上新增专属页面与脚本，并充分借鉴已实现的 “AI 理财助手” 模块结构，可以快速落地“AI 每日学堂”。该方案不但提供系统化的微课程和实践活动，还兼顾用户隐私与伦理教育，符合个人网站的整体风格和技术架构。随着内容的不断积累和功能的迭代，“AI 每日学堂”有望成为用户长期学习 AI 的首选平台。
