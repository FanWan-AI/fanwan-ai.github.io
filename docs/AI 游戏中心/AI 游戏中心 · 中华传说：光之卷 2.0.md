# AI 游戏中心 · 中华传说：光之卷 (Chinese Legend: Scroll of Light) - 产品需求文档 (PRD) v3.0 完整增强版

> **版本说明**：v3.0 (在 v2.0 基础上进行全方位增强，达到可执行级别)
> **核心理念**：将语文知识深度转化为玩家在游戏世界中的核心力量与特权。

---

## 1. 产品定位与差异化策略

### 1.1 市场定位分析
**目标缺口**：现有教育游戏多为“轻度游戏化”，缺乏深度心流体验。本产品瞄准“中重度教育RPG”蓝海市场，以 **“知识即力量”** 为核心理念，构建沉浸式学习体验。

### 1.2 核心差异矩阵
| 维度 | 传统教育游戏 | **《中华传说：光之卷》** |
|------|-------------|------------------------|
| **动机** | 外部奖励驱动（星星、金币） | **内在叙事驱动**（拯救世界、个人成长） |
| **知识呈现** | 割裂的题目 | **知识技能化、道具化、环境化** |
| **反馈机制** | 对/错 + 积分 | **丰富的游戏性反馈**（战斗特效、剧情推进、世界变化） |
| **长期动力** | 消耗型奖励 | **构建型成长**（收集、建造、社交展示） |
| **AI角色** | 出题器/评分器 | **智能导师、动态剧情生成器、个性化挑战设计师** |

### 1.3 年级差异化设计 (扩展细化)

#### 🟢 筑基期 (1-2年级) - “启蒙·墨林初探”
*   **核心能力**：拼音、基础汉字（300字）、简单量词、笔画顺序。
*   **交互设计**：
    *   **语音全覆盖**：所有界面文字均有清晰、慢速的童声朗读（支持开关）。怪物攻击前有语音提示（“我要用‘火’字旁攻击你啦！”）。
    *   **触觉反馈**：答题正确时，设备轻微震动（如支持）。
    *   **操作简化**：战斗界面仅有两个大按钮——“攻击”（毛笔图标）、“治疗”（葫芦图标）。技能在特定剧情后自动获得，无需手动装备。
    *   **辅助系统**：战斗中出现“求助羽毛”，点击后可高亮正确答案轮廓一次（每场战斗限用1次）。
*   **怪物设计**：
    *   **偏旁小妖**：身体由“艹”、“扌”等偏旁组成，弱点是用对应偏旁的字攻击。
    *   **笔画蜗牛**：移动缓慢，玩家需要按正确笔顺画出汉字才能对其造成伤害。
    *   **拼音泡泡怪**：吐出带有声母/韵母的泡泡，玩家需点击正确的组合。

#### 🔵 结丹期 (3-4年级) - “积累·文海寻踪”
*   **核心能力**：成语、同反义词、古诗背诵、基本修辞（比喻、拟人）、标点符号。
*   **交互设计**：
    *   **组合技引入**：技能栏扩展至4个，技能可产生连携效果。例如，先使用“春风化雨”（恢复技能，需填写描写春天的诗句），再使用“桃李芬芳”（攻击技能，需填写带“花”的成语），伤害提升50%。
    *   **属性克制**：知识体系化为五行属性。**金（字词辨析）→木（句式结构）→土（古诗文）→水（阅读理解）→火（成语典故）→金**，形成循环克制。
    *   **限时挑战**：部分精英怪会开启“墨滴沙漏”倒计时，在限定时间内完成题目可造成额外伤害。
*   **怪物设计**：
    *   **成语九头蛇**：每个头代表一个成语空缺字，玩家需按顺序击败所有头（填对所有空）。
    *   **标点符号幽灵**：会释放“混乱迷雾”，使玩家题目中的标点消失，玩家必须正确补充。
    *   **反义镜像魔**：生成玩家的镜像，玩家必须用反义词攻击（如镜像用“寒冷”，玩家需选“炎热”）。

#### 🔴 元婴期 (5-6年级) - “思辨·古今问道”
*   **核心能力**：文言文断句与翻译、复杂修辞辨析、中心思想归纳、写作逻辑、文学常识。
*   **交互设计**：
    *   **策略深度**：Boss战引入“机制破解”。例如，Boss“文言古魔”会周期性地进入“文言之体”状态，只接受文言文翻译题的攻击。
    *   **环境互动**：关卡场景中出现可交互的“古文碑刻”、“对联残卷”，解读后可获得永久Buff或开启隐藏道路。
    *   **多目标战斗**：同时出现2-3个目标，各自需要不同类型的题目攻击（如一个需改病句，一个需诗词接龙），考验优先级判断。
*   **怪物设计**：
    *   **阅读迷雾**：非实体怪物，会展开一段短文，并提问3个问题。玩家必须在限定时间内连续答对，迷雾才会散去。
    *   **论证结构兽**：攻击方式为抛出论点，玩家需选择正确的论据或指出其逻辑错误来反击。
    *   **文学史巨像**：由不同朝代的文学知识构成，玩家需按历史顺序攻击其弱点。

## 2. 游戏世界观与叙事架构 (扩展)

### 2.1 核心设定
*   **墨魂宇宙**：万物由“墨魂”书写而成。上古贤者仓颉造字，墨魂凝聚为“光之卷”，维持世间文脉。
*   **灾变**：因世人“提笔忘字”、“言语粗鄙”、“经典蒙尘”，负面情绪滋生“浊气”，污染墨魂，化为“墨魇”。世界陷入混乱，文明之光黯淡。
*   **玩家**：被“光之卷”残页选中的 **“御墨师”** ，拥有感受和驾驭墨魂的天赋。
*   **终极目标**：游历九大“文域”，修复“光之卷”，重燃文明之火。

### 2.2 核心NPC与势力
*   **引路人·笔老**：一支成精的毛笔，幽默唠叨，负责新手引导和系统说明。
*   **守护之灵·字灵**：被净化的汉字/成语所化，既是战斗伙伴，也是知识库。
*   **中立势力·书局**：提供任务、兑换物品、查阅典籍（错题本）。
*   **敌对势力·浊教**：由“忘字之魔”、“抄袭之鬼”、“污言之王”统领，目标是让世界重归蒙昧。

### 2.3 剧情推进模式
*   **主线剧情**：线性推进，解锁新区域，揭示世界危机根源。
*   **支线任务**：由各地NPC发布，通常与特定语文知识点或文化常识相关（如帮“对联精”找下联，为“断句仙”整理古文）。
*   **随机事件**：探索地图时随机触发，如“墨雨”（快速答对字音题获得经验加成）、“字谜宝箱”。

## 3. 核心系统深度设计

### 3.1 战斗系统 (回合制) - 详细流程与数值框架

#### 3.1.1 战斗界面布局
```
[敌人区]        [战斗日志]
   🐉            “错别字怪使用了‘混淆攻击’！”
[玩家角色区]     [题目面板]
   🧙            “请选出下列词语中的错别字：”
[技能区]        [选项区]
[⚔️][🔥][🛡️][💊]  A. 故弄玄虚  B. 故弄弦虚
```

#### 3.1.2 战斗回合详解
1.  **速度判定**：基于玩家“敏捷”属性与怪物速度决定先手。
2.  **玩家行动阶段**：
    *   **选择技能**：点击技能图标。
    *   **咏唱/出题**：弹出与技能绑定的题目面板。题目难度和类型由技能决定。
    *   **答题与反馈**：
        *   **答对**：技能释放成功。伤害基础值 = 技能基础伤害 × (1 + 知识掌握度系数)。**知识掌握度系数**由该知识点历史正确率动态计算（如正确率90%，系数为0.9）。
        *   **答错**：技能释放失败，受到“墨力反噬”，损失HP（最大生命的5%），并可能附加“困惑”状态（下回合题目选项随机隐藏一个）。
        *   **完美答对**（极快速度+正确）：触发“文思泉涌”效果，伤害为150%，并获得1点“墨意”。
3.  **敌人行动阶段**：
    *   **常规攻击**：玩家进入“防御姿态”，需完成一道防御性题目（如修改病句、选择正确读音）来减免伤害。完全答对减免70%，答错则全额承受。
    *   **技能攻击**：敌人释放特殊技能，可能需特定类型的题目来“打断”或“净化”。
4.  **回合结束**：更新状态效果。

#### 3.1.3 属性与数值 (示例)
*   **玩家属性**：
    *   **文力 (ATK)**：影响技能基础伤害。通过升级和装备笔灵提升。
    *   **文心 (DEF)**：影响伤害减免。通过装备和字灵羁绊提升。
    *   **文思 (MP)**：即“墨意”，上限为100，释放技能消耗，随时间缓慢恢复。
    *   **文敏 (SPD)**：影响先手几率。
    *   **文韵 (CRIT)**：影响完美答对的触发几率和暴击伤害。
*   **伤害计算公式**（简化版）：
    `最终伤害 = (文力 + 技能基础值) × (1 + 知识掌握系数 + 属性克制系数) × (1 - 敌人抗性)`

### 3.2 字灵收集与养成系统

#### 3.2.1 字灵获取
*   **净化捕获**：击败怪物后概率触发“净化”小游戏（如拼字、组词），成功则获得该字灵。
*   **剧情赠送**：关键NPC赠送。
*   **合成进化**：特定字灵可通过消耗材料合成进阶（如“日”+“月” = “明”）。

#### 3.2.2 字灵属性
每个字灵包含：
*   **形象**：独特的国风卡通设计。
*   **类型**：攻击型、防御型、辅助型。
*   **元素属性**：对应语文知识大类（字、词、句、篇）。
*   **天赋技能**：被动效果。如：
    *   **“雷”字灵**：答对字形题时，10%几率对敌方全体造成溅射伤害。
    *   **“思”字灵**：每场战斗第一次答错时，免除反噬伤害。
    *   **“群”字灵**：组队战斗时，提升全队防御力。
*   **羁绊系统**：收集相关联的字灵可激活羁绊，获得额外属性。
    *   **例**：同时拥有“春”、“夏”、“秋”、“冬”四字灵，激活羁绊“四季轮回”，全属性提升5%。

#### 3.2.3 字灵培养
*   **升级**：消耗“经验墨滴”（战斗获得）。
*   **突破**：消耗相同字灵碎片或通用碎片，提升等级上限并强化天赋。
*   **装备“文饰”**：可装备三个位置的文饰（如“玉佩”、“印章”、“流苏”），提供额外属性加成。

### 3.3 笔灵（武器）与砚台（装备）系统

*   **笔灵**：改变攻击风格和题目倾向。
    *   **狼毫笔**：攻击+20%，题目速度要求+30%。
    *   **羊毫笔**：防御+15%，治疗技能效果+25%。
    *   **紫毫笔**：文韵(暴击)+10%，但文思(MP)消耗+20%。
    *   **兼毫笔**：平衡型，无显著优缺点。
*   **砚台**：提供特殊被动效果。
    *   **端砚**：每场战斗第一次答题时间延长2秒。
    *   **歙砚**：答错题时，有20%几率不进入冷却，可立即重答。
    *   **澄泥砚**：提升从藏经阁净化错题时获得的奖励。

### 3.4 家园系统：“我的书院”
*   **功能**：玩家可自由布置的个性化空间。
*   **模块**：
    *   **藏书阁**：错题本的实体化。错题化为“黑色书卷”陈列，净化后变为“金色书卷”。点击可回顾。
    *   **字灵斋**：展示已收集的字灵，可在此与字灵互动，了解其背景故事。
    *   **墨池**：每日可在此“练笔”，完成一组随机基础题，获得少量资源。
    *   **公告板**：展示好友动态、系统公告。
*   **建造与装饰**：通过任务和活动获得的家具（书案、盆景、字画）可装饰书院，部分稀有家具提供全局属性加成。

### 3.5 社交系统
*   **好友**：互访书院，每日可“赠墨”（赠送体力）。
*   **组队副本（3人）**：
    *   **诗词接龙阵**：需要连续接龙，错误或超时全队承伤。
    *   **文胆挑战**：接力完成一篇短文的阅读理解，每人负责一部分。
*   **异步竞赛**：
    *   **墨榜**：按周结算，根据“知识净化总量”（答题量×正确率）排名，奖励头像框、称号。
    *   **书院风采大赛**：玩家投票评选最美书院。

### 4.3 AI内容生成管道（开发阶段）

创建 `tools/ai_content_generator.py` 脚本，使用大语言模型批量生成高质量内容。

```python
# 示例：生成成语题目
prompt = """
```

## 5. 美术、音频与UX规范

### 5.1 美术风格指南
*   **核心风格**：**新国风卡通**。线条圆润流畅，色彩饱和度适中，在传统国画基础上增加现代卡通的光影和质感。
*   **UI组件**：以“卷轴”、“竹简”、“宣纸”、“印章”为基底。按钮状态应有清晰的反馈（正常、悬停、点击、禁用）。
*   **字体**：
    *   标题：汉仪旗黑、思源宋体。
    *   正文：站酷快乐体（低年级）、阿里巴巴普惠体（高年级）。
    *   所有游戏内文字（非UI）均可切换显示拼音。

### 5.2 音频设计
*   **BGM**：
    *   主界面/书院：宁静悠扬的古风乐曲，以古筝、笛子为主。
    *   墨林（低年级）：活泼、好奇的调子，加入铃铛、木鱼音色。
    *   荒原（中年级）：略带苍凉和探险感，融入马头琴、萧。
    *   云宫（高年级）：空灵、宏大，以管弦乐结合古琴。
    *   战斗：节奏明快，紧张但不压迫。
*   **音效**：
    *   **答题正确**：清脆的“叮”声，伴随墨迹晕开的辅助音。
    *   **答题错误**：短促低沉的“噗”声。
    *   **技能释放**：根据技能类型定制（“火”技能有燃烧声，“水”技能有流水声）。
    *   **UI交互**：毛笔划过纸面的“沙沙”声。

### 5.3 无障碍设计
*   **色盲模式**：为所有战斗状态（弱点、克制、增益、减益）提供图案标识，不单纯依赖颜色。
*   **键盘导航**：支持全键盘操作，Tab键切换焦点，空格/回车键确认。
*   **阅读辅助**：所有剧情文本可通过方向键或点击逐句播放。
