# AI 游戏中心 · 中华传说：光之卷 (Chinese Legend: Scroll of Light) - 产品需求文档 (PRD) v2.0

> **版本说明**：v2.0 (由 v1.0 升级)
> **核心理念**：拒绝“换皮做题”，打造真正的“教育 RPG”。
> **技术架构**：纯前端 (Static Web) + AI 离线生成内容 + LocalStorage 存档。

---

## 1. 产品愿景与核心差异

### 1.1 拒绝枯燥
市面上的教育游戏大多是“做题-得金币-买装扮”的弱关联模式。
**我们要做的**：**题目即武器，知识即力量**。
*   答对题目不是为了得金币，而是为了**发动攻击**。
*   题目的难易度决定了攻击的威力。
*   语文知识点（如成语、修辞）直接化身为**技能**（如“排比连击”、“夸张护盾”）。

### 1.2 目标用户
*   **核心玩家**：小学 1-6 年级学生。
*   **核心诉求**：喜欢《口袋妖怪》、《原神》等有收集、养成、战斗要素的游戏。

### 1.3 年级差异化设计 (Grade Differentiation)
为了满足不同年龄段的认知需求，游戏将分为三个“境界”：

#### 🟢 筑基期 (1-2 年级) - “听音辨形”
*   **核心内容**：拼音、识字、笔画、简单反义词。
*   **交互特点**：
    *   **全程语音**：题目和选项均支持朗读。
    *   **超大字体**：减少视觉疲劳，所有汉字标注拼音。
    *   **操作简化**：仅保留“攻击”和“吃药”，无需复杂的技能组合。
*   **怪物风格**：呆萌可爱，如“拼音团子”、“偏旁小怪”。

#### 🔵 结丹期 (3-4 年级) - “词句连贯”
*   **核心内容**：成语积累、关联词填空、句式变换、古诗背诵。
*   **交互特点**：
    *   **技能组合**：引入属性克制（如“水”属性成语克制“火”属性怪物）。
    *   **限时挑战**：战斗增加倒计时，训练反应速度。
*   **怪物风格**：具象化，如“成语接龙蛇”、“反义双子”。

#### 🔴 元婴期 (5-6 年级) - “文意通达”
*   **核心内容**：阅读理解、修辞手法、文言文入门、作文逻辑。
*   **交互特点**：
    *   **深度策略**：Boss 战需要阅读短文寻找弱点（如：Boss 只有在被“比喻句”攻击时才掉血）。
    *   **多步解谜**：需要先修复古文残卷，才能解锁 Boss 房间。
*   **怪物风格**：压迫感强，水墨写意，如“阅读迷雾”、“文言古魔”。

## 2. 游戏世界观：水墨幻想

*   **背景**：世界由“墨魂”构成。由于人们提笔忘字，墨魂被“浊气”污染，化为“墨魇”。
*   **玩家身份**：**御墨师** (Ink Master)。
*   **核心道具**：**光之卷** (The Scroll)。玩家通过收集失落的汉字、成语，修复光之卷，净化世界。
*   **美术风格**：**新国风 (Neo-Chinese Style)**。
    *   UI 采用卷轴、印章、毛笔元素。
    *   怪物设计结合汉字结构（如“病”字旁的怪物会咳嗽，“火”字旁的怪物全身燃烧）。

---

## 3. 核心玩法循环 (Core Loop)

### 3.1 战斗系统 (The Battle) - 核心体验
采用 **回合制 RPG (Turn-Based RPG)** 模式。

1.  **遭遇敌人**：玩家在地图上遇到“错别字怪”。
2.  **玩家回合**：
    *   玩家选择**技能**（普通攻击、技能卡）。
    *   **咏唱阶段 (Casting)**：系统弹出一道语文题。
        *   *普通攻击* = 基础字词辨析（简单，速度快）。
        *   *必杀技* = 复杂句式/诗词填充（困难，伤害高）。
    *   **判定**：
        *   **答对**：角色挥动毛笔，墨迹化为特效攻击敌人。
        *   **答错**：咏唱失败，角色被墨水反噬（扣血/眩晕）。
        *   **完美回答**（速度快且无误）：触发“暴击” (Critical Hit)。
3.  **敌人回合**：
    *   敌人发动攻击，玩家需进行**防御判定**（如：快速选出句子中的语病来格挡伤害）。
4.  **胜利结算**：
    *   获得经验值、金币。
    *   **捕获/净化**：有概率将怪物净化为“字灵” (Word Spirit)，成为伙伴。

### 3.2 养成系统 (Progression)
*   **字灵收集 (Collection)**：
    *   类似宝可梦。每个字灵对应一个汉字或成语。
    *   例：捕获“雷”字灵，获得被动技能“雷霆”（答对题目有几率造成溅射伤害）。
*   **笔灵升级**：
    *   玩家的武器是“毛笔”。
    *   通过闯关解锁不同材质的笔（狼毫、羊毫、兼毫），改变攻击属性（如：狼毫笔攻击高但题目难，羊毫笔回血）。

## 4. 详细功能模块

### 4.1 关卡设计 (Level Design)
地图分为不同“卷轴” (Chapters)：

*   **第一卷：初入墨林 (拼音与字形)**
    *   怪物：声母蝙蝠、偏旁部首怪。
    *   Boss：**多音字魔王**（它会切换形态，玩家必须根据它的读音切换攻击方式）。
*   **第二卷：成语荒原 (词汇与成语)**
    *   怪物：反义词双子、成语填空兽。
    *   Boss：**画蛇添足巨蟒**（玩家必须在它画完脚之前击败它，否则直接秒杀）。
*   **第三卷：诗词云宫 (古诗文)**
    *   怪物：绝句鸟、律诗守卫。
    *   Boss：**李白之影**（通过接下句诗词来对决）。

### 4.2 技能体系 (Skills)
技能不仅仅是特效，而是与语文知识结合：

*   **技能：火眼金睛**
    *   效果：去除一个错误选项。
    *   消耗：10 点墨意。
*   **技能：排比连击**
    *   效果：连续出 3 道简单的同类题目，全部答对造成 300% 伤害。
*   **技能：博古通今**
    *   效果：遇到古诗题时，伤害翻倍。

### 4.3 错题本：藏经阁
*   玩家答错的题目会被“封印”在藏经阁。
*   **复习机制**：玩家必须定期去藏经阁“净化”错题（重做），否则错题会变成“心魔”在战斗中随机捣乱（如遮挡选项）。

## 5. 技术实现方案 (Web Friendly)

鉴于我们是 GitHub Pages 静态站点，采用 **Client-Side Logic + Pre-generated Content** 模式。

### 5.1 数据结构 (JSON)
题目库不依赖后端数据库，而是加载静态 JSON 文件。

```json
// question_bank_grade2.json
{
  "id": "q_101",
  "type": "choice",
  "difficulty": 1,
  "tags": ["pinyin", "monster_weakness_fire"],
  "question": "下列哪个字的读音是 'chuí'？",
  "options": [
    {"text": "垂", "isCorrect": true},
    {"text": "睡", "isCorrect": false},
    {"text": "吹", "isCorrect": false}
  ],
  "explanation": "垂 (chuí) - 垂直；睡 (shuì) - 睡觉；吹 (chuī) - 吹风。"
}
```

### 5.2 存档机制
*   使用 `localStorage` 存储用户存档（SaveData）。
*   结构：
    ```json
    {
      "playerLevel": 5,
      "unlockedStages": ["stage_1_1", "stage_1_2"],
      "inventory": ["item_potion", "spirit_lei"],
      "mistakes": ["q_101", "q_205"] // 错题ID列表
    }
    ```

### 5.3 AI 的角色 (The Dungeon Master)
我们不实时调用 LLM API（延迟高、成本高），而是利用 AI **生成内容包**。
*   **开发流**：使用 `tools/ai_llm.py` 批量生成题目 JSON。
*   **Prompt 策略**：
    *   "请生成 50 道适合小学二年级的成语填空题，其中 10 道包含陷阱选项，并输出为 JSON 格式。"
    *   "请为 Boss '多音字魔王' 设计 5 句台词，每句台词里都包含一个多音字。"

## 6. 开发路线图 (Roadmap)

### Phase 1: 原型机 (The Prototype) - *Current Focus*
*   **目标**：实现核心战斗循环。
*   **内容**：
    *   一个简单的 HTML5 Canvas 或 DOM 页面。
    *   玩家 vs 1 个木桩怪。
    *   点击“攻击” -> 弹出题目 -> 答对扣血。
    *   简单的血条 UI。

### Phase 2: 冒险模式 (The Adventure)
*   **目标**：加入地图和关卡进度。
*   **内容**：
    *   关卡选择界面（地图）。
    *   3 种不同的怪物（对应拼音、字形、成语）。
    *   结算界面（星级评价）。

### Phase 3: 养成与特效 (The Polish)
*   **目标**：增加粘性。
*   **内容**：
    *   字灵图鉴。
    *   攻击特效（粒子效果）。
    *   音效与背景音乐。
