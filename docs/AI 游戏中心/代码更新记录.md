# 代码更新记录

## 2025-12-08 - v3.0.0-alpha: 核心战斗与存档系统重构

### 1. 状态管理重构 (State Management Refactor)
- **结构升级**: 将扁平的 `this.state` 重构为符合 v3.0 PRD 的深层结构：
    - `player`: 包含 `stats` (ATK, DEF, SPD, CRIT), `level`, `exp`, `ink`.
    - `enemy`: 包含 `stats` (ATK, DEF).
    - `combat`: 追踪 `turn` (player/enemy) 和 `phase` (select/attack_quiz/defense_quiz).
    - `progress`: 包含 `unlockedLevels`, `completedLevels`.
- **数据持久化**: 实现了 `saveData()` 和 `loadSaveData()`，基于 `localStorage` 保存玩家进度和属性。

### 2. 战斗系统深度增强 (Combat System Depth)
- **防御阶段 (Defense Phase)**: 
    - 新增 `startEnemyTurn()` 逻辑。
    - 敌人攻击时不再直接扣血，而是触发 **防御答题**。
    - 答对题目可触发格挡 (Block)，减少 70% 伤害；答错则承受全额伤害。
- **暴击机制 (Critical Hits)**:
    - 实现了“完美回答”判定：3秒内答对题目。
    - 效果：伤害 x1.5 并恢复 10 点墨意 (Ink)。
- **数值计算**:
    - 伤害公式引入攻防差值：`Damage = EnemyAtk * (100 / (100 + PlayerDef))`.

### 3. 交互与反馈 (UX/UI)
- **战斗反馈**: 新增 "CRIT!" (暴击) 和 "BLOCKED!" (格挡) 的飘字效果。
- **流程优化**: 修复了关卡解锁逻辑，确保胜利后正确解锁下一关并保存进度。

## 2025-12-08 - v3.0.1-alpha: 字灵收集系统 (Spirit Collection)

### 1. 字灵系统 (Spirit System)
- **数据结构**: 在 `state.collection` 中新增 `spirits` 数组，用于存储已捕获的字灵 ID。
- **图鉴 UI**: 
    - 新增 `spirit-screen` (图鉴界面)，支持网格化展示字灵卡片。
    - 未获得的字灵显示为灰色问号，已获得的字灵显示图标、名称和描述。
    - 在主界面和地图界面添加了“字灵图鉴”入口按钮。
- **掉落逻辑**: 
    - 战斗胜利后有 30% 几率触发“字灵捕获”。
    - 优先掉落未收集的字灵。
    - 结算界面会显示捕获提示。

## 2025-12-08 - v3.0.2-alpha: 视觉表现与工具链升级 (Visuals & Tooling)

### 1. 视觉特效增强 (Visual FX Upgrade)
- **动态战斗**:
    - **投射物系统 (Projectiles)**: 实现了 `spawnProjectile()` 方法，支持不同类型的攻击特效（墨汁、火焰、雷电）。

## 2025-12-08: 题库质量与随机性修复 (v3.6)

### 1. 题库清洗与规范化
*   **移除英文题目**: 扫描并移除了所有 JSON 题库中意外生成的英文题目，确保游戏内容的纯净性。
*   **生成器升级**: 更新了 `generate_daily_questions.py` 的系统提示词 (System Prompt)，强制要求 LLM 仅输出中文内容（拼音除外），并明确了各境界的中文描述。

### 2. 游戏逻辑修复
*   **随机性增强**: 修复了题目加载后顺序固定的问题。现在 `loadQuestions` 会在加载 JSON 后立即对题目数组进行洗牌 (Shuffle)，确保每次进入游戏的题目顺序都不同。
*   **防御题库扩充**: 移除了防御阶段仅能使用 `subtype: defense` 题目的限制。现在敌人攻击时会从整个题库中随机抽取题目，彻底解决了“敌人攻击题目重复”的问题。
*   **防御护盾特效**: 防御成功时，玩家角色周围会出现蓝色护盾特效。
*   **界面居中**: 修复了“字灵图鉴”窗口未居中的问题，优化了遮罩层样式。

### 3. 内容扩充
*   **智能生成器升级**: 优化了 `generate_game_questions.py` 的 Prompt，增加了“无剧透”指令和更多样化的题目要求。
*   **题库扩容**: 新增了 10 道三年级成语题作为测试，验证了新生成器的稳定性。

### 4. Bug 修复
*   修复了 Boss 战中普通血条和 Boss 血条显示混乱的问题。
*   修复了防御阶段超时后逻辑卡死的问题。

*   **智能检测**: 游戏逻辑 (`game.js`) 现在会自动检测题目中是否包含拼音字符，并自动应用优化后的字体样式。

### 3. 视觉与交互微调

## 2025-12-08: 生产环境配置与拼音修正 (v3.4)

### 1. 自动化管线迁移 (Pipeline Migration)
*   **DeepSeek 集成**: 将每日内容生成工作流迁移至 DeepSeek LLM，利用其更强的中文理解能力生成高质量题目。
*   **工作流合并**: 将游戏内容生成任务合并至主工作流 `academy-daily.yml`，统一管理每日自动化任务，减少维护成本。
*   **配置更新**: 废弃了旧的 OpenAI 配置，全面转向 DeepSeek API。

### 2. 拼音渲染深度修复 (Pinyin Rendering Deep Fix)
*   **字体栈重构**: 针对用户反馈的“一声调号偏移”问题，将 `.pinyin-text` 的字体栈调整为 `"Segoe UI", "Microsoft YaHei", "Arial"`。这些字体在 Windows 平台上对 Unicode 预组合字符（如 `ā`）有完美的渲染支持。
*   **生成规则强化**: 在 `generate_daily_questions.py` 中增加了严格的 Prompt 指令，强制要求 LLM 输出预组合字符 (Precomposed Unicode)，杜绝“字母+组合变音符”导致的显示错位。

### 3. 开发体验优化
*   **本地调试支持**: 优化了 `generate_daily_questions.py`，增加了对本地 `.env` 文件的自动加载支持，方便开发者在本地环境进行测试和调试。

## 2025-12-08: 境界系统与题库重构 (v3.5)

### 1. 题库架构重构 (Data Architecture)
*   **分级存储**: 将原有的单一题库 `questions_v3.json` 拆分为 6 个独立文件 (`questions_grade_1_lianqi.json` 等)，分别对应 6 个游戏境界。
*   **境界映射**: 建立了完整的“年级-境界”映射体系：
    *   一年级 -> 练气期 (Lianqi)
    *   二年级 -> 筑基期 (Zhuji)
    *   三年级 -> 结丹期 (Jiedan)
    *   四年级 -> 元婴期 (Yuanying)
    *   五年级 -> 化神期 (Huashen)
    *   六年级 -> 大乘期 (Dacheng)

### 2. 内容生成升级 (Content Generation 2.0)
*   **差异化 Prompt**: 针对每个境界设计了专属的生成指令 (Prompt)，确保题目类型与难度精准匹配。
    *   **练气期**: 侧重拼音、笔画、象形字。
    *   **大乘期**: 侧重文言文、历史典故、复杂逻辑。
*   **智能去重**: 引入了基于 MD5 的哈希去重机制。生成新题目时，会自动计算题目文本的哈希值并与现有题库比对，确保“每日新题”绝对不重复。

### 3. UI 适配
*   **境界选择器**: 更新了游戏主界面的选择器，采用 3列网格布局，清晰展示 6 大境界。
*   **动态加载**: 游戏逻辑现在会根据选择的境界动态加载对应的 JSON 题库文件，大幅降低了单次加载的数据量。
