# ✅ VSCode Agent 实现 Prompt（复制即用）

你是一个世界级的**游戏开发工程师 + 游戏系统设计师**。请在本地工程中从零实现一款面向小学 1–6 年级、符合“数学王国”世界观的教育游戏 **Math Kingdom**，要求可直接运行（本地开发），画面精美、交互丰富、玩法上瘾，并且架构可扩展到 2–6 年级。

## 0. MVP 范围（必须完成）

### MVP 只做 1 年级大陆：**数字森林**

实现 4 个可玩的迷你关卡 + 一个可反复刷的“无限挑战模式”，形成可持续循环：

1. **捡果子：数字认识与排序**
   拖拽果子到对应数字篮子（1–20 可配置），包含“比较大小”扩展题。

2. **河流搭桥：10 以内加减法**
   给出目标桥长，玩家拖动木板（1,2,3…）组合凑目标值；错误会掉木板，答对桥逐渐成形。

3. **形状积木屋：基础几何形状**
   选择正确形状（正方形/长方形/圆形/三角形）填入缺口，完成房屋建造。

4. **四季分类：简单分类与整点时间**
   把物品拖到春夏秋冬区域；然后出现整点钟表选择题（例如 3:00）。

5. **无限挑战：森林试炼**
   从题库随机生成题目（数字/加减/形状/分类/时间混合），引入连胜、暴击、道具与排行榜（本地）。

### 成瘾机制（必须有）

* **连胜倍数**：连续正确 → 经验/金币倍率上升
* **能量条/精灵陪伴**：答对给能量，答错扣能量，能量满触发“精灵技能”（提示/去错项/时间冻结）
* **装饰与建造**：用金币装饰“数学小屋”（房子 UI 场景即可，不做 3D）
* **进度与成就**：新手 10 分钟内能拿到第一个称号/徽章（高兴点）

### 自适应难度（必须有）

根据玩家表现（正确率/用时/连续错题点）动态调节：

* 题目难度、题量、倒计时
* 失败时给“更容易一题”回血，并显示温和的引导提示

## 1. 技术选型（按此执行）

* 使用 **React + TypeScript + Vite** 创建项目（Web 端）
* 画面采用**2D 卡通风格**：CSS + SVG + Canvas（任选，建议 PixiJS 或纯 Canvas）
* 动画：Framer Motion（如果不用也可自己实现）
* 音效：Howler.js
* 存档：localStorage（玩家等级、金币、装饰、小屋、成就、错题记录、难度参数）
* 题库数据：JSON 文件（按年级/主题划分）

目标：`npm install && npm run dev` 一键启动。

## 3. 视觉与交互（必须达到“精美”）

### UI 目标

* 大字体、圆角卡片、柔和阴影、儿童友好
* 主色调：森林绿 + 温暖黄（但不要土）
* 动画：按钮点击、奖励弹窗、连胜倍数浮动、精灵能量条发光
* 每个迷你游戏都有独立场景背景（可用渐变 + SVG 树木云朵）

### 角色

* 一个“数学精灵”作为陪伴：浮动在 UI 角落，会说话（Dialog 气泡）
* 精灵提供提示与鼓励，不批评

## 4. 游戏系统详细规则（必须实现）

### 4.1 经济与成长

* 经验 XP：完成关卡给 XP，XP → 等级
* 金币 Coin：用于小屋装饰（装饰只是 UI 物件/贴纸即可）
* 星星 Star：关卡评级（按正确率+时间+连胜）

### 4.2 道具（至少 3 个）

* 提示（显示正确方向/去除一个错误选项）
* 冻结（倒计时暂停 3 秒）
* 修复（桥掉落一次自动补回）

道具可用金币买或连胜奖励。

### 4.3 错题本

记录错题 tag（例如 `add-10`, `shape-square`），在“学堂”里可复习，复习后给奖励（避免孩子逃避错题）。

## 5. 题库与数据（必须落地）

请为 1 年级生成一份 `data/ai/games/math-kingdom/grade1/tasks.json`：

* 每个任务含：

  * `id`
  * `domain`（number/addsub/shape/classify/time）
  * `difficulty`（1–5）
  * `prompt`
  * `payload`（游戏所需数据：数字列表、目标值、选项等）
  * `explain`（给精灵讲解用）
  * `tags`

题目数量：

* 每个 domain 至少 30 条（总 150+），可用程序生成 + 固定模板混合。
