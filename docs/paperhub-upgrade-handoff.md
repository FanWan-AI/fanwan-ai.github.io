# 论文中心实施交接（2026-09-10）

## 当前实现

页面使用 `assets/paperhub/` 的共享契约、渲染器、按需加载器和样式。当前版只读取最新一期与日期索引；归档逐期读取，经典轨迹在展开方向时获取。中文解读不截断，保留英文原题、原始摘要、作者报告与条件、边界和建议对照实验。摘要哈希保存在数据中，不在页面展示。

英文／西语界面能切换，但新解读目前只生成中文，界面明确说明，不复制英文摘要伪装中文。旧期仅展示有完整中文摘要且具备论文身份的记录；2026-09-09 的讨论帖不再混入论文精选。经典资料保留原始整理日期，本次未逐篇重新审核历史内容。

## 生成与发布

Node 22+；`npm ci --ignore-scripts` 后运行测试。

```powershell
npm run research:test
$env:PAPERHUB_OUTPUT_DIR = '.tmp/paperhub-preview'
node --env-file=.env tools/paperhub/generate.mjs --publish
```

默认不传 `--publish` 仍访问来源与付费模型，只是不写文件；离线验证应运行测试。正式发布目录为 `data/ai/scholarpush`。密钥仅通过环境变量 `DEEPSEEK_API_KEY` 注入。

- `.github/workflows/ai-blog.yml`：每天 UTC 00:00／北京时间 08:00，工作流名称为 **AI Paper Hub Daily**。Pages 的 `workflow_run` 已同步更名。
- 默认候选上限 8、解读上限 5、模型调用上限 1、输出上限 12000 token、任务超时 15 分钟。
- 从 arXiv Atom API 获取完整摘要和版本身份，主要查询 cs.AI；只有成功请求但日期窗为空时才间隔后查询另一固定分类。来源服务报错立即停止，不用 URL 变体绕过限流。
- 日期窗默认 7 日，不是所有 AI 方向的穷尽检索，也不能据此宣称“今日全球最佳论文”。当前做同一期身份排重，尚未实现跨全部历史的语义选题排重。
- 每条解读校验中文、句末、引文对应和数值；单条不合格剔除并记录错误码，全部不合格则失败，旧版不变。
- 写盘前验证并暂存全部文件，最新索引最后替换；普通写盘错误回滚。Git 提交是线上多文件发布单位，不宣称能抵抗硬件故障的跨文件事务。

## 验证与限制

已运行真实 DeepSeek 请求并人工核对摘要，最终发布两篇：VIP-Router、Improve & Prune。含无引用数值的候选被排除；移除一处摘要不支持的“首次”断言；规范化 TeX 百分号、千位分隔符与倍数表示，避免正确数字被误拒。

这不是全文精读或复现实验。数字与原文相符不能证明论文结论正确，自动规则也不能替代语义审查。首次真实运行与离线测试不等于长期调度稳定。
